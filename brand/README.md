# STAG brand assets

**stag-ecosystem-logo.jpg** is the official $STAG Ecosystem logo (the full-resolution master the owner supplied).
It shows the hooded stag with gold antlers and neon green eyes, holding two glowing orbs:

- left: **StagR CRM** (the field-service CRM and the mobile app)
- right: **StagHouseRecords** (the music label)
- banner: **$STAG ECOSYSTEM**

Style rules the owner has set for everything built from it:

- Colours: neon green (#39ff14 family) and gold on black.
- The stag is always a mature, fierce ADULT. Never cute, never a baby or chibi.
- Stickers and animations: transparent background, real performed actions (character enters the frame and does something),
  not bouncing or shaking, and no text.
- Never use the Hooded 20 NFT art.
- Junk Junkies is a separate brand: black lifted RAM with neon green graffiti, crew kids in black caps with the JJ logo,
  hi-vis green vests and green-and-black sneakers.
- No Indiana references on the STAG / StagR site.

The smaller web versions are in `relaunch/a/` (stag-ecosystem.webp, stag-ecosystem-sm.webp, og-stag.jpg).
